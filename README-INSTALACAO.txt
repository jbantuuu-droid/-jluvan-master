J LUVAN MASTER PRO — V3 PWA

PUBLICAR NO GITHUB PAGES
1. Descompacte este ZIP.
2. Envie TODO o conteúdo desta pasta para a RAIZ do repositório GitHub jluvan-master.
3. Substitua os ficheiros existentes quando o GitHub perguntar.
4. Confirme que index.html está na raiz, ao lado de manifest.json e sw.js.
5. Em Settings > Pages, mantenha: Deploy from a branch / main / (root).
6. Espere a publicação e abra o endereço no Safari.
7. Safari > Partilhar > Adicionar ao ecrã principal.

NOTAS
- O app funciona sem dependências externas e guarda progresso, notas, checklist e preços no navegador deste dispositivo.
- Após atualizar, feche e abra o app novamente. Se ainda vir a versão antiga, no Safari atualize a página uma vez.
- Cálculos são apoio de estudo e estimativa. Obras exigem projeto, normas aplicáveis, dados de campo e validação profissional.
